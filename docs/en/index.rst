Linux on ESP SoCs
=================

The ESP Linux platform provides comprehensive software support for ESP SoCs,
including hardware enablement, bootloader components (SPL and U-Boot),
OpenSBI, the Linux kernel, Linux distributions, and application development
tools.

This documentation helps developers build, configure, customize, and
develop software for ESP SoCs running Linux.

The documentation is organized into the following sections:

Getting Started
---------------

Learn how to set up the development environment, boot Linux on an ESP SoC
board, and run your first Linux application.

Application Development
-----------------------

Learn how to develop Linux applications, including cross-compilation,
deployment, debugging, and interaction with Linux system services.

System Development
------------------

Learn how to build and customize Linux system images, including root
filesystem generation, package management, and system integration using
Buildroot, Yocto Project, or OpenWrt.

Platform Development
--------------------

Learn how to customize the Linux platform for ESP SoCs, including boot
flow, bootloader configuration, Linux kernel configuration, device tree,
board support, and hardware enablement.

Examples
--------

Build and run self-contained Linux userspace examples for ESP SoCs.
