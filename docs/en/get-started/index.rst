Getting Started
===============

This section helps you quickly get started with Linux on ESP SoCs.
It provides the basic steps required to set up the development
environment, boot a prebuilt Linux system, and run your first Linux
application.

The Getting Started process includes the following steps:

#. **Set up the development environment** — install the required host
   tools and cross-compilation toolchain.

#. **Boot Linux on the board** — flash a prebuilt Linux image and connect
   to the board console.

#. **Build and run your first application** — cross-compile a Linux
   application, deploy it to the target board, and verify the output.
