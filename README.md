# esp-linux-examples

This repository is a container for examples, getting started guides and other content related to Espressif's Linux software platform.

## Repository layout

```text
esp-linux-examples/
├── docs/
│   └── en/
│       └── get-started/
└── examples/
    └── get-started/
```

- [`docs/`](docs/README.md) contains the ESP-Docs/Sphinx website sources and
  local build instructions.
- [`examples/`](examples/README.rst) contains self-contained Linux userspace
  applications for ESP SoCs.

See [`CONTRIBUTING.md`](CONTRIBUTING.md) before adding documentation or an
example.
