Examples
========

Examples are grouped by purpose:

* ``get-started/`` contains the smallest examples for learning the build and
  run workflow.
* ``network/`` contains networking and HTTP service examples.

Each example must be self-contained and include:

* A ``README.rst`` describing its purpose, prerequisites, build, deployment,
  and expected output
* Source code under ``src/``
* A build file
* SPDX license identifiers

Shared setup and deployment procedures belong in the main documentation and
should be linked rather than copied.
