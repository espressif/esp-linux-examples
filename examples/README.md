# Examples

Examples are grouped by purpose:

- [`get-started/`](get-started/README.md) contains the smallest examples for
  learning the build and run workflow.

Each example must be self-contained and include:

- A `README.md` describing its purpose, prerequisites, build, deployment, and
  expected output
- Source code under `src/`
- A build file
- SPDX license identifiers

Shared setup and deployment procedures belong under [`docs/`](../docs/README.md)
and should be linked rather than copied.
